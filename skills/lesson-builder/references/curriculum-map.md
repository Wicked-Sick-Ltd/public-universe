# Curriculum map (England): where PublicUniverse fits

Use these topic areas for curriculum links. Name the area. Don't quote statutory wording you haven't verified, and don't give exam-board spec reference numbers.

| Stage | Subject area | Good PublicUniverse hooks |
|---|---|---|
| Year 1 | Science: seasonal changes (day length across seasons) | Sun's rise/set times each week from the Sun page |
| KS1 | Geography: simple compass directions | "Which way do we face to see Saturn?" |
| KS1–2 | Maths: comparing and ordering, place value | Planet sizes, 1.5 million+ asteroids |
| Year 3 | Science: light (the Sun can be dangerous; shadows) | Sun altitude at midday vs shadow length |
| Year 5 | Science: Earth and space (planets orbit the Sun, the Moon orbits Earth, spherical bodies, day and night) | Orrery through a year; periods of each planet |
| KS2 | Maths: statistics (tables, bar and line graphs), time | Planet data tables; Halley returns in 2061 |
| KS3 | Physics: space physics (gravity, weight = mass × g, the Solar System, seasons and tilt, light-year) | Gravity per planet; axial tilts; scale model in AU |
| KS3 | Maths: ratio, standard form | Scale models; masses and distances |
| KS4 | GCSE Physics: space physics (Solar System, orbital motion). This is in separate (triple) physics for most boards | v = 2πa/T; orbital speed vs distance |
| KS4 | GCSE Maths: standard form, graphs | Real masses; log-scale discussion |
| KS4 | GCSE Computer Science: data, APIs, programming | Call the REST API, parse JSON |
| KS5 | A-level Physics: gravitational fields, circular orbits, Kepler's third law (astrophysics option) | Fit T² = (4π²/GM)a³ to find the Sun's mass; Jupiter's mass from its moons |
| KS5 | A-level Maths: statistics, regression, logarithms | log–log fits; asteroid size distributions |
| KS5 | A-level Computer Science (NEA), EPQ | SQL on the downloadable 1.5 m-row SQLite catalogue |
